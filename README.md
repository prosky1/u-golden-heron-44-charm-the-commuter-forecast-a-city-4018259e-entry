One line of weather for a city that does not exist — an entry for the
[make.fun bounty "Charm the Commuter: Forecast a City That Isn't"](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e).

`main.ts` writes the forecast to `/output/entry.txt`:

> Tomorrow in Nowhere: light rain of lost umbrellas, with a 90 percent chance the bus never comes.

Run it with Node 22.18 or later:

```sh
node main.ts
```
